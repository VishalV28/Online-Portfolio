# Vishal Vichare - Portfolio Website

A modern, reactive personal portfolio built with vanilla HTML, CSS & JavaScript.


## ✨ Features

- **Dark Glassmorphism Design** — Deep navy palette with frosted glass cards
- **Typed Text Animation** — Cycling through your titles in the hero
- **Scroll Animations** — Elements fade in as you scroll down
- **3D Tilt Effect** — Project cards react to mouse movement
- **Responsive** — Looks great on mobile, tablet, and desktop
- **Zero Dependencies** — Pure HTML/CSS/JS, no framework needed
- **Fast** — No build step, instant load

## 📝 Customization

- **Contact Form**: Replace `https://formspree.io/f/placeholder` in `index.html` with your actual Formspree endpoint (free at [formspree.io](https://formspree.io))
- **Profile Photo**: Add your photo to `assets/images/` and reference it in the About section
- **Project Links**: Update GitHub links in the project cards
- **Colors**: Edit CSS variables in `:root` at the top of `css/style.css`
